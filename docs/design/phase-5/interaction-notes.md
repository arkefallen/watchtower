# P5-D01 Interaction Notes & State Behavior

## 1. Edge Decay Curve Mechanics (FR-6.4)
- **Time Lag Buckets:**
  - `0-1h`: $[0, 60)$ minutes. Highlighted as the **Golden Capture Zone** with Signal Amber border/fill.
  - `1-6h`: $[60, 360)$ minutes.
  - `6-24h`: $[360, 1440)$ minutes.
  - `>24h`: $\ge 1440$ minutes.
- **Empty Bucket Handling:**
  - When a bucket has 0 trades, it renders empty (`—`) rather than displaying a misleading `0%` win rate or `0.00%` ROI.
- **Low-Sample Guardrail:**
  - When `sampleSize < 5` (configurable `minSample`), the UI displays a warning banner: `INSUFFICIENT SAMPLE (< 5 TRADES) — DATA SHOWN FOR OBSERVATION ONLY, NOT STATISTICAL SIGNIFICANCE`.
  - Prevents premature conclusions on edge durability.

## 2. Manual Trade Logging & Thesis Validation (FR-6.3)
- **Mandatory Thesis Constraint:**
  - Submitting an empty or whitespace-only thesis is rejected **server-side** with a field-level error: `"Thesis is required for manual trades"`.
  - The UI highlights the textarea with a `#D87870` border and renders an inline error.
  - `AUTO` trades generated by blockchain ingestion do not require a thesis.
- **Followed Wallet Pinning:**
  - If the user selects an explicit followed wallet in the manual trade form, the trade is saved with `isLinkPinned: true`.
  - The auto-linker skips pinned trades and never overwrites manual attribution.

## 3. Personal Dashboard Aggregations (FR-6.5)
- **Realized vs Unrealized PnL:**
  - Closed positions / executed sales contribute to `totalPnlUsd`.
  - Open positions are isolated from realized PnL and displayed in a distinct `Unrealized PnL` card.
- **Multi-angle Breakdown:**
  - By Followed Wallet: lists trade counts, net PnL, and average lag minutes to identify the most profitable signals.
  - By Token: audits per-token exposure and profitability.
  - By Lag Bucket: directly answers "when I follow within 1h do I actually win?"

## 4. Comparison Table Semantics (FR-6.6)
- **Verdict Calculation:**
  - `CAPTURED`: When `userRoiPct >= walletRoiPct`. Styled in Signal Amber text with a filled dot.
  - `DECAYED`: When `userRoiPct < walletRoiPct`. Styled in Risk Red text with an open dot.
  - `—`: When followed wallet ROI is unknown or null (e.g. followed wallet position has not closed, or price unavailable). Rendered with no verdict to avoid misleading assumptions.
