# Local Watchtower fonts

Geist and Geist Mono are the Latin variable WOFF2 subsets served by Google
Fonts, retrieved on 2026-09-06. Material Symbols Outlined is the full variable
WOFF2 font, preserving the icon names and fill settings already used throughout
the application. The adjacent license files apply to their respective fonts.

Sources: `fonts.googleapis.com` / `fonts.gstatic.com`; licenses from
`google/fonts` (Geist and Geist Mono) and `google/material-design-icons`.

These assets keep the approved Stitch typography and existing navigation icons
available without external browser requests. Health reads `APP_TIMEZONE` at
request time; timestamps and data do not depend on the font service.
